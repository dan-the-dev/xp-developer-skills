# Checklist — before touching legacy

- [ ] Confirmed area is **under-tested** for the intended change (Feathers legacy definition)
- [ ] **Change points** named (symbols / files)
- [ ] **Test points** candidate identified (entry + observables)
- [ ] **Effect sketch** or bullet list of ripple (variables, I/O) — optional but valuable
- [ ] **Pinch point** chosen or reason noted if impossible
- [ ] Plan for **seam** type (object/link/compile) at high level
- [ ] No expectation of **pure refactoring** without first **green characterization** (unless adding tests only)
