# Spike checklist — before explore

- [ ] **One** hypothesis / question (not a backlog of unknowns)
- [ ] **Success** and **failure** signals defined
- [ ] **Time box** set
- [ ] **Out of scope** includes delivery concerns (pyramid, catalogs, prod design) unless those *are* the question
- [ ] **`spike/<slug>` branch** created; no spike work planned on main / feature branch
- [ ] Wrong skill ruled out (not bugfix, not full ATDD/TDD slice, not legacy harness unless only feasibility unknown)
- [ ] Charter recorded (`docs/spikes/<slug>.md` or equivalent)
