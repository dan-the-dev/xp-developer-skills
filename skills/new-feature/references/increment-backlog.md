# Increment backlog

Default path: **`increments/<feature-stem>.md`** at repo root (or project convention).

```markdown
# Increments — <feature title>

## Increments (ordered)

- [ ] <one releasable slice — one sentence>
- [x] <slice> — PR #… / `acceptance-examples/…` / `test-lists/…`
```

One line = one **`skills/new-increment`** cycle. Mark `[x]` only when that increment’s ATDD+TDD work is integrated per team policy.
