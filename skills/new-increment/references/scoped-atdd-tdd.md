# Scoped ATDD + TDD

| Artifact | Path (default) |
|----------|----------------|
| Example catalog | `acceptance-examples/<increment-stem>.md` |
| Test list | `test-lists/<increment-stem>.md` |

Do **not** put future increments’ examples in these files.

Order: Discuss examples (ATDD) → Distill acceptance → test list (TDD) → Develop (acceptance RED, inner TDD, acceptance GREEN).
